## 🚀 Quick Start

### GitHub Pages Deployment

1. Go to repository **Settings** → **Pages**
2. Select **Deploy from a branch**
3. Choose **main** branch and **/ (root)** folder
4. Save

Your site will be live at: `https://btptax.github.io/btp-tax-consulting`

### Vercel Deployment

1. Visit [https://vercel.com/new](https://vercel.com/new)
2. Connect your GitHub repository
3. Click Deploy
4. Your site goes live automatically with every push

### Netlify Deployment

1. Visit [https://app.netlify.com/start](https://app.netlify.com/start)
2. Connect your GitHub repository
3. Click Deploy site
4. Custom domain configuration available in Netlify dashboard

## 🎨 Customization

### Colors
Edit CSS variables in the `<style>` section:
```css
:root{
  --navy: #16233F;
  --gold: #B8892B;
  --cream: #F6F2E9;
  /* ... more colors ... */
}
```

### Typography
Uses Google Fonts:
- **Fraunces** (serif) - Headlines
- **Inter** (sans-serif) - Body text
- **IBM Plex Mono** (monospace) - Data/Registration

### Content
Edit text directly in HTML sections:
- Hero section: Update headline, description, CTA buttons
- About section: Company description and details
- Services section: Service list and descriptions
- Contact form: Service options and form fields
